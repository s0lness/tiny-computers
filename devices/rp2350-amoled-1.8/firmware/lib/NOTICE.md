# Third-party code in this directory

Everything under `packs/rp2350-touch-amoled-18/firmware/lib/` is **Waveshare's**, taken from the
demo package that ships with the RP2350-Touch-AMOLED-1.8 board. It is the
panel driver, the touch controller, the IMU, the shared pin configuration and
the PIO program that drives the display over QSPI.

It is included here so the firmware builds with one command. None of it was
written for this project.

## Two files that carry no header, and why they are still here

Checked file by file rather than assumed, because redistributing someone
else's code on the wrong terms is not a mistake that can be walked back.

- **`QMI8658/QMI8658.c` and `QMI8658.h`** carry no licence header at all.
  They arrived in the same Waveshare demo package as every other file in this
  directory, all of which do, so they are redistributed here on the same
  terms. If Waveshare state otherwise, this is the file to correct and those
  are the files to remove.
- **`QSPI_PIO/qspi.pio.h`** is generated by `pioasm` from `qspi.pio`, which
  does carry the notice. It is a build artefact and regenerates; it is kept
  only so the tree builds without the PIO assembler installed.

## What is not in here

The Pico SDK is referenced by the build, not copied. `third_party/lucide/`
carries its own ISC licence. Everything under `firmware/apps/`,
`firmware/runtime/` and `tools/` is this project's own work, under the
repository's MIT licence.
